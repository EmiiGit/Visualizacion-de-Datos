# 📈 Visualización de Datos Estadísticos (UBA)

## 📌 Descripción del Problema
La capacidad de sintetizar y comunicar hallazgos complejos es una de las habilidades más críticas en Ciencia de Datos. Este repositorio contiene el proyecto final de Visualización Estadística de la Universidad de Buenos Aires (UBA), enfocado en la exploración y representación gráfica de grandes volúmenes de datos para extraer *insights* de valor.

## 🛠️ Stack Tecnológico
- **Lenguaje:** R
- **Visualización de Datos:** ggplot2, plotly, lattice
- **Reportes:** RMarkdown, LaTeX (PDF)

## 🔬 Metodología Aplicada
- **Diseño Visual Efectivo:** Selección de las gráficas adecuadas (dispersión, cajas, densidad, series temporales) en función de la naturaleza de las variables y la pregunta de negocio.
- **Análisis de Componentes Principales (PCA) / Clustering:** Apoyo visual para técnicas de reducción de dimensionalidad o agrupación.
- **Storytelling con Datos:** Redacción del informe final integrando explicaciones estadísticas formales con gráficos limpios y estéticos.

## 📊 Resultados Técnicos
El proyecto concluyó con la entrega de un informe analítico robusto (`Trabajo_Practico_Visualizacion-Estadistica_UBA.pdf`), demostrando habilidad para mapear datos complejos en formatos visuales comprensibles y estadísticamente precisos. La reproducibilidad del código se aseguró mediante el uso de RMarkdown.
